**이번 회차의 한계 (중요)**
- X/Threads 유저 원문은 사실상 확보하지 못했다. 확인된 X 글은 2건(A-F1 근거), Threads는 팁/홍보글 몇 건뿐이며, "이런 앱 없나" 류 직접 요청 글은 거의 없었다. 검색 도구가 site:/정확문구 연산자를 지원하지 않았고 reddit·threads.net 도메인 필터는 오류를 냈다. WebFetch는 DNS 오류로 원문을 열지 못했다.
- 따라서 근거 대부분은 블로그, 앱스토어 리뷰, HN/GitHub/클리앙/블라인드 요약, 뉴스, 벤더 글(편향 가능) 등 간접 자료이며 각 항목에 플랫폼을 명시했다. 인용은 검색 결과에 실제 나온 문구만 사용했다. 수요 규모는 별도 검증(인터뷰, 로그인 가능한 도구로 X/Threads/Reddit 재확인)이 필요하다.
- 앱 인지도 수치(사용자 수/순위)는 대부분 '확인 불가'로 남았다. '시장 공백 가능성'은 검색 범위 내 판단일 뿐 앱스토어 전수 조사가 아니다.
