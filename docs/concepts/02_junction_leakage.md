# 개념 노트 02: 저장 노드 접합 누설

> 노트북: `notebooks/02_devsim_leakage.ipynb` · 코드: `memdev/silicon.py`, `memdev/dram/devsim_junction.py`, `memdev/dram/d2.py`

## 1. 저장 노드는 다이오드다

DRAM 셀의 커패시터는 접근 트랜지스터의 n+ 영역(저장 노드)에 붙어 있고, 그 아래는 p형 웰입니다. 그래서 저장 노드는 **n+/p 접합**입니다. '1'(Vdd)을 저장하면 n+ 쪽 전압이 높아 이 접합에 **역방향 전압**이 걸리고, 역방향 다이오드의 작은 전류가 커패시터의 전하를 빼 갑니다.

## 2. 역방향 누설의 두 성분

| 성분 | 원리 | 크기 | 활성화 에너지 |
|---|---|---|---|
| 생성 | 공핍층의 트랩을 거쳐 전자-정공 쌍이 생기고 전계에 끌려감 | ≈ q·n_i·W/(2τ) | ≈ Eg/2 ≈ 0.56 eV |
| 확산 | 중성 영역의 소수 캐리어(n_i²/N)가 공핍층으로 확산 | ∝ n_i²/N | ≈ Eg ≈ 1.12 eV |

- **SRH 생성률** U = (np − n_i²)/(τp(n+n1) + τn(p+p1)). 공핍층에서는 n, p ≪ n_i라서 U ≈ −n_i/(2τ), 즉 생성이 됩니다.
- **τ(캐리어 수명)** 는 트랩이 많을수록 짧습니다. 생성 전류는 1/τ에 비례하므로, 결함을 줄이는 공정이 곧 리텐션 개선입니다.
- **W(공핍층 폭)** = √(2ε(Vbi+V_R)/q · (1/NA + 1/ND)). 역방향 전압이 크면 넓어져 생성 전류가 늘어납니다.
- **n_i(T)** = √(Nc·Nv)·exp(−Eg/2kT). 온도에 지수적으로 민감합니다.

## 3. 왜 시뮬레이터로 푸나

공식 q·n_i·W/(2τ)는 공핍층 전체에서 생성이 최대라고 가정한 **상한**입니다. 실제로는 공핍층 가장자리에서 생성이 줄고 확산이 더해집니다. DEVSIM은 포아송 방정식과 전자·정공 연속 방정식을 격자 위에서 함께 풀어 이걸 계산합니다. 85°C, 1.5 V에서 시뮬레이션의 생성 성분은 공식 상한의 약 0.50배였습니다.

## 4. 시뮬레이션하면서 고친 두 가지

1. **n_i 온도 의존이 빠진 기본 모델**: DEVSIM의 기본 물리 모델은 n_i를 1e10 cm⁻³ 상수로 둡니다. 그대로 두면 온도를 바꿔도 누설이 변하지 않습니다. n_i(T)를 직접 계산해 넣었습니다.
2. **수치 상쇄 오차**: 단자 전류는 다수 캐리어의 큰 드리프트·확산 전류의 차이로 계산되는데, 배정밀도 오차(약 1e-10 A/cm²)가 누설 신호(1e-9 A/cm²)를 덮었습니다. 0 V에서 0이 아닌 전류가 나온 원인입니다. 생성률 적분과 소수 캐리어 전류처럼 **정밀도가 좋은 성분만 더해** 해결했고, 0 V 전류는 1.5 V 전류의 1e-15배 수준으로 내려갔습니다.

## 5. 결과에서 읽을 것

- **온도**: 1/kT 대 log J 그래프에서 생성은 Eg/2, 확산은 Eg 기울기를 따릅니다. 확산이 온도에 더 민감해서 고온일수록 비중이 커지고, 이 구조에서는 약 95°C에서 확산이 생성을 넘습니다. 65°C 이상에서 맞춘 전체 활성화 에너지는 약 0.86 eV입니다.
- **τ**: 생성 성분은 1/τ에 정확히 비례합니다(τ 1 µs → 0.1 µs에서 10.0배).
- **NA**: 이 모델에서는 NA가 클수록 누설이 줄지만, **전계 강화 터널링을 넣지 않은 모델의 한계**입니다. 실제로는 도핑이 높을수록 접합 전계가 세져 트랩 보조 터널링이 급증하므로, 저장 노드 접합은 도핑 경사를 완만하게 만듭니다.
- **셀당 누설**: τ = 1 µs, 면적 1e-11 cm²이면 85°C에서 약 0.006 fA로, 01의 가정값 2.5 fA보다 수백 배 작습니다. τ를 약 1 ns로 줄여야 가정값 수준이 됩니다. SRH 생성만으로는 실제 누설을 설명하기 어렵고, 트랩 보조 터널링이나 GIDL 같은 메커니즘이 필요하다는 뜻입니다. 이 차이를 어떻게 다룰지는 D3(모델 추출)에서 정합니다.

## 6. 한계

- 1차원 급격 접합. 실제는 3차원이고 도핑이 경사져 있음.
- 전계 강화·트랩 보조 터널링, 밴드 간 터널링 미포함.
- 트랩은 밴드갭 중앙 하나, τn = τp.
- 확산 성분은 단자까지의 거리(구조 길이)에 의존.
- 실리콘 물성 상수는 기억에 의존한 값(원문 미확인), 나머지 파라미터는 가정값.
