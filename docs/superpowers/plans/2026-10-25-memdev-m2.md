## 사전 조사로 확정한 사실 (스파이크, 2026-10-25)

1. DEVSIM `simple_physics`는 `n_i = 1e10`을 온도와 무관한 상수로 둔다. 온도 효과를 보려면 `n_i`, `n1`, `p1`을 직접 온도의 함수로 설정해야 한다.
2. 단자 전류를 그대로 읽으면 다수 캐리어 전류의 큰 드리프트·확산 항이 상쇄되면서 배정밀도 오차(≈1e-10 A/cm²)가 신호(1e-9 A/cm²)를 덮는다. 0 V에서 1e-10의 잔류 전류, 저전압 순서 역전의 원인. **정밀도 안전 전류**: `J = |q·Σ(USRH·NodeVolume)| + |Jn(p쪽 단자)| + |Jp(n+쪽 단자)|`(역방향 바이어스에서 세 성분은 같은 방향). 이 식으로 0 V 전류 1e-25, 단조 증가, 격자 100배 변화에 0.1% 이내.
3. 바이어스를 한 번에 올리면 수렴 실패가 잦다. 0.1 V씩 올리면 극단 조합 16개(NA 1e16–1e18, ND 1e18–1e20, 0–95°C, τ 1e-10–1e-3 s) 모두 수렴.
4. `solve`는 메모리의 모든 소자를 함께 푼다. 같은 프로세스에서 반복 계산하려면 계산마다 `reset_devsim()`이 필요하다(없으면 두 번째부터 연쇄 실패).
5. 수렴 기준은 `absolute_error=1e10, relative_error=1e-12`(절대 기준 사실상 해제). 실행 시간은 한 번에 약 0.2초.
6. DEVSIM은 C 수준 stdout으로 반복 로그를 수백 줄 출력하며 `debug_level`로 끌 수 없다.
7. 기준값(NA 1e17, ND 1e19, τ 1 µs, 85°C, 1.1 V)에서 J ≈ 2.5e-7 A/cm². 접합 면적 1e-11 cm²이면 셀당 약 0.003 fA로, M1 가정값 2.5 fA보다 약 1000배 작다. SRH 생성만으로는 실제 DRAM 누설을 설명하지 못한다는 뜻이며(전계 강화·트랩 보조 터널링, GIDL, 짧은 수명), 노트북과 문서에 그대로 밝힌다.

스파이크 코드: 스크래치 폴더 `m2spike/` (버림).

```python
import pytest
from memdev.silicon import (bandgap_ev, built_in_potential, depletion_width_cm, generation_bound, ni_silicon)
from memdev.params import values

def test_bandgap_room_temperature():
    assert bandgap_ev(26.85) == pytest.approx(1.1245, abs=2e-3)

def test_ni_room_temperature_near_1e10_and_rises():
    assert ni_silicon(26.85) == pytest.approx(1.0e10, rel=0.10)

def test_built_in_and_depletion_width():
    vbi = built_in_potential(26.85, 1e17, 1e19)
    assert 0.9 < vbi < 1.05
    w0 = depletion_width_cm(26.85, 1e17, 1e19, 0.0)
    assert 0.08e-4 < w0 < 0.15e-4
    assert depletion_width_cm(26.85, 1e17, 1e19, 1.0) > w0

def test_generation_bound_scales_inverse_tau():
    a = generation_bound(85.0, 1e17, 1e19, 1e-6, 1.0)
    assert generation_bound(85.0, 1e17, 1e19, 1e-7, 1.0) == pytest.approx(10 * a)

    with pytest.raises(ValueError):
        generation_bound(25.0, 1e17, 1e19, 0.0, 1.0)

def test_junction_params_present():
    v = values("dram_baseline")
    assert (v["na"], v["nd"], v["tau_srh"], v["j_area"]) == (1e17, 1e19, 1e-6, 1e-11)
```

- Produces:
  - `class JunctionSimError(RuntimeError)` — 메시지에 "수렴하지 못했습니다"와 조건(°C, NA, ND, τ, V)을 담는다
  - `@dataclass(frozen=True) JunctionResult(temp_c: float, na: float, nd: float, tau: float, biases_v: list[float], j_total: list[float], j_gen: list[float], j_diff: list[float])` — 단위 A/cm². `j_gen = |q·Σ USRH·NodeVolume|`, `j_diff = |Jn(p 단자)| + |Jp(n+ 단자)|`, `j_total = j_gen + j_diff`
  - `simulate_junction(*, temp_c: float, na: float, nd: float, tau: float, biases_v: Sequence[float], length_cm: float = 1e-4, xj_cm: float = 0.5e-4, fine_cm: float = 1e-8, max_iterations: int = 60) -> JunctionResult`
- 구조: 길이 1 µm, 위쪽(x=0~xj) n+ = 저장 노드(단자 "top", 역방향 바이어스를 여기 건다), 아래쪽 p 웰(단자 "bot", 접지). 격자: 양 끝 `length/50`, 접합 `fine_cm`.
- 구현 순서(스파이크에서 확정): `reset_devsim()` → 메시·소자 생성 → `SetSiliconParameters(T)` 후 `n_i`, `n1`, `p1`을 `ni_silicon(temp_c)`로, `taun`=`taup`=τ로 덮어씀 → 전위만 풀기(`absolute_error=1.0, relative_error=1e-12`) → 드리프트-확산 풀기(`absolute_error=1e10, relative_error=1e-12`) → 각 목표 바이어스까지 0.1 V씩 램프 → 정밀도 안전 전류 계산. 바이어스는 오름차순만 허용, 음수는 `ValueError`(순방향 미지원).
- 모든 DEVSIM 호출은 `_quiet()` 안에서: fd 1·2를 `os.devnull`로 `dup2`하고 끝나면 복원(예외 시에도). DEVSIM 예외는 `JunctionSimError`로 바꾼다.

```python
# tests/devsim/test_junction.py
import math, subprocess, sys
import pytest
from memdev.colab import DEVSIM_MATH_LIBS
import os
os.environ.setdefault("DEVSIM_MATH_LIBS", DEVSIM_MATH_LIBS)
HAS_DEVSIM = subprocess.run([sys.executable, "-c", "import devsim"], capture_output=True).returncode == 0
pytestmark = pytest.mark.skipif(not HAS_DEVSIM, reason="devsim not available")

from memdev.dram.devsim_junction import JunctionSimError, simulate_junction  # noqa: E402
from memdev.silicon import generation_bound  # noqa: E402

BASE = dict(temp_c=85.0, na=1e17, nd=1e19, tau=1e-6)

def test_zero_bias_current_negligible_and_monotonic():
    r = simulate_junction(**BASE, biases_v=[0.0, 0.25, 0.5, 1.0, 1.5])
    assert r.j_total[0] < 1e-6 * r.j_total[-1]
    assert all(b > a for a, b in zip(r.j_total[1:], r.j_total[2:]))

def test_mesh_converged():
    a = simulate_junction(**BASE, biases_v=[1.0], fine_cm=1e-7).j_total[0]
    b = simulate_junction(**BASE, biases_v=[1.0], fine_cm=1e-9).j_total[0]
    assert a == pytest.approx(b, rel=0.01)

def test_generation_below_analytic_bound_and_close_at_high_bias():
    j = simulate_junction(**BASE, biases_v=[1.5]).j_gen[0]
    bound = generation_bound(85.0, 1e17, 1e19, 1e-6, 1.5)
    assert 0.3 * bound < j <= bound

def test_generation_scales_inverse_lifetime():
    a = simulate_junction(**{**BASE, "tau": 1e-6}, biases_v=[1.0]).j_gen[0]
    b = simulate_junction(**{**BASE, "tau": 1e-7}, biases_v=[1.0]).j_gen[0]
    assert b / a == pytest.approx(10, rel=0.05)

def test_activation_energy_between_half_gap_and_gap():
    j65 = simulate_junction(**{**BASE, "temp_c": 65.0}, biases_v=[1.1]).j_total[0]
    j95 = simulate_junction(**{**BASE, "temp_c": 95.0}, biases_v=[1.1]).j_total[0]
    k = 8.617333262e-5
    ea = math.log(j95 / j65) / (1 / (k * 338.15) - 1 / (k * 368.15))
    assert 0.5 < ea < 1.2

@pytest.mark.parametrize("na,nd,temp_c,tau", [(1e16, 1e18, 0.0, 1e-3), (1e18, 1e20, 95.0, 1e-10),
                                              (1e16, 1e20, 95.0, 1e-3), (1e18, 1e18, 0.0, 1e-10)])
def test_repeated_runs_in_one_process(na, nd, temp_c, tau):  # Review Focus 1
    r = simulate_junction(temp_c=temp_c, na=na, nd=nd, tau=tau, biases_v=[0.0, 1.5])
    assert r.j_total[1] > 0

def test_failure_is_wrapped_and_recoverable():  # Review Focus 2
    with pytest.raises(JunctionSimError, match="수렴하지 못했습니다"):
        simulate_junction(**BASE, biases_v=[1.5], max_iterations=1)
    assert simulate_junction(**BASE, biases_v=[1.0]).j_total[0] > 0

def test_forward_bias_rejected():
    with pytest.raises(ValueError):
        simulate_junction(**BASE, biases_v=[-0.1])

def test_no_solver_output_leaks(capfd):  # Review Focus 5
    simulate_junction(**BASE, biases_v=[1.0])
    out, err = capfd.readouterr()
    assert "Iteration" not in out + err and "RelError" not in out + err
```
