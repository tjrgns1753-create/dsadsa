# memdev M0–M1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 저장소 뼈대·Colab 실행 기반(M0)과 DRAM 스펙·셀 기본 물리·슬라이더 노트북(M1)을 만든다.

**Architecture:** `memdev` 파이썬 패키지에 계산을 모으고, 노트북은 jupytext percent 형식 소스(`notebooks/src/*.py`)에서 생성·실행해 결과를 포함한 `.ipynb`로 저장한다. Colab은 GitHub 공개 저장소를 직접 열고, 첫 셀이 저장소를 clone 하고 `memdev.colab.setup()`으로 ngspice·DEVSIM·한글 폰트를 준비한다.

**Tech Stack:** Python ≥3.11, numpy, scipy, matplotlib, pyyaml, ipywidgets, pytest, jupytext, nbconvert, ngspice(apt), DEVSIM 2.11.2(pip).

**Spec:** `docs/superpowers/specs/2026-10-25-memdev-design.md` (개정 2)

**Out of scope for this plan:** M2(DEVSIM 접합 누설)~M6, M2b. 각각 M1 완료 후 별도 계획서로 작성한다.

## Global Constraints

- 저장소: `https://github.com/tjrgns1753-create/dsadsa` (public), 작업 브랜치 `claude/feature-research`.
- 내부 단위는 SI(F, A, V, s). 온도는 API에서 °C로 받고 내부에서 K로 변환한다.
- 모든 파라미터는 `memdev/params/*.yaml`에 `value, unit, low, high, source, status`를 가진다. `status` ∈ {`assumed`, `unverified`, `verified`}.
- 모든 그래프 제목 또는 주석에 "시뮬레이션"과 파라미터 세트 이름을 표시한다.
- 그래프 문구는 한국어. Colab에서 한글이 깨지지 않아야 한다.
- DEVSIM은 `DEVSIM_MATH_LIBS=libopenblas.so.0:liblapack.so.3:libblas.so.3`가 import 전에 설정돼야 한다.
- ngspice·DEVSIM이 없는 환경에서는 해당 테스트를 skip 하고 사유를 출력한다.
- 커밋 메시지 끝에 세션의 attribution 줄을 붙인다. 모델 이름을 코드·문서에 넣지 않는다.

## Review Focus

1. **슬라이더 극단값**: Cs가 작아 읽기 실패 전압이 Vdd 이상이 되면(예: Cs=2 fF) 리텐션 0으로 처리하고 "읽기 불가"를 표시해야 하며, 음수 시간이나 예외가 나오면 안 된다. → Task 5, 6 테스트.
2. **Colab 한글 폰트**: 기본 Colab에는 한글 폰트가 없다. 그래프의 한글이 네모로 나오면 안 된다. → Task 3 테스트(글리프 누락 경고 0건).
3. **설치 셀 재실행**: Colab에서 첫 셀을 두 번 실행해도(이미 clone 됨, 이미 설치됨) 오류 없이 넘어가야 한다. → Task 3, 4.
4. **배열 입력**: 온도·시간을 numpy 배열로 넣어도 계산이 원소별로 동작해야 한다(노트북 sweep에서 사용). → Task 5 테스트.
5. **물리적으로 불가능한 입력**: 누설 전류 ≤ 0, Cs ≤ 0, 절대영도 미만 온도는 `ValueError`. → Task 5 테스트.

```python
# tests/crosscheck/test_ngspice_rc.py
import math, pytest
from memdev.ngspice import run_batch, parse_meas, has_ngspice

requires_ngspice = pytest.mark.skipif(not has_ngspice(), reason="ngspice not installed")

RC = """* RC leak
C1 n1 0 10f IC=1.1
R1 n1 0 1e14
.tran 1m 2 UIC
.control
run
meas tran t_fail WHEN v(n1)=0.85 FALL=1
quit
.endc
.end
"""

@requires_ngspice
def test_rc_decay_matches_analytic():
    t = parse_meas(run_batch(RC), "t_fail")
    assert t == pytest.approx(math.log(1.1 / 0.85) * 1.0, rel=0.01)

def test_parse_meas_missing_raises():
    with pytest.raises(KeyError):
        parse_meas("no measurements here", "t_fail")
```

### Task 5: 셀 기본 물리 (cell.py, leakage.py)

**Files:**
- Create: `memdev/dram/cell.py`, `memdev/dram/leakage.py`
- Test: `tests/invariants/test_cell.py`, `tests/invariants/test_leakage.py`

**Interfaces:**
- Consumes: `memdev.units.celsius_to_kelvin`, `K_B_EV`
- Produces (모든 함수 numpy 배열 입력 지원):
  - `bitline_signal(v_cell, vdd: float, cs: float, cbl: float)` → `(v_cell - vdd/2) * cs / (cs + cbl)`
  - `fail_voltage(vdd: float, cs: float, cbl: float, sense_min: float) -> float` → `vdd/2 + sense_min*(cs+cbl)/cs`
  - `cell_voltage(t_s, v0: float, i_leak, cs: float)` → `max(v0 - i_leak*t/cs, 0)` (일정 전류 근사)
  - `retention_time(v0: float, v_fail: float, i_leak, cs: float)` → `cs*(v0 - v_fail)/i_leak`, `v_fail >= v0`이면 `0.0`
  - `arrhenius_leakage(temp_c, i_ref: float, t_ref_c: float, ea_ev: float)` → `i_ref*exp(-ea/k*(1/T - 1/T_ref))`
  - 입력 검증: `cs <= 0`, `i_leak <= 0`, `i_ref <= 0` → `ValueError`
